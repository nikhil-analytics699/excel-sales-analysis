
# Excel Sales Analysis Project

## Project Overview
This project analyzes 500 sales records using Microsoft Excel to identify sales trends, product performance, regional performance, and payment preferences.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas and functions

## Skills Demonstrated
- Data Cleaning and Formatting
- Sorting and Filtering
- SUM, AVERAGE, COUNT, COUNTA
- IF, AND, OR
- SUMIF, SUMIFS
- COUNTIF, COUNTIFS
- VLOOKUP
- PivotTables and Charts
- KPI Dashboard Creation

## Key Performance Indicators
| Metric | Result |
|---|---:|
| Total Revenue | ₹1,32,08,210 |
| Total Orders | 500 |
| Quantity Sold | 1,505 |
| Average Order Value | ₹26,416.42 |

## Key Business Insights
- West generated the highest regional revenue.
- Laptops were the highest-revenue product.
- Electronics was the top-performing category.
- Net Banking generated the highest revenue among payment methods.

## Project Files
- `Excel_Sales_Analysis_Beginner_Project.xlsx` – Excel workbook containing the cleaned dataset, analysis, PivotTables, charts, and dashboard.

## Objective
To develop practical Excel skills and demonstrate how sales data can be cleaned, analyzed, and converted into meaningful business insights.
